# Sector Rotation weights

Each weight sets how much one measure counts toward the score. A higher weight gives that measure more say. Type a new weight from 1 to 5. The table totals update on your device right away.

Fill from data sets every row with a data feed to the latest economic reading and leaves the rest unchanged. Treat it as a starting point. This page teaches you to read the economy, so change any reading where your own view differs.
