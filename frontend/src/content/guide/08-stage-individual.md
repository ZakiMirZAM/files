# Stage 5: one company

The Individual page is the full report for one company. Open the page from the Individual item in the left menu. A search box appears. Type a stock symbol (the short code that identifies a company, for example MSFT for Microsoft). Matching companies appear as you type, and you can click one. There are also quick-pick buttons for a few well-known companies. Click Analyze to load the report.

## What the page shows

At the top is the current share price (the price one share trades at right now). Next to it is an estimate of value per share, which is what the page calculates the share could be worth based on the company's own numbers. Comparing the two is the point of the page.

Below that are the company's results over several years. The page shows profit measures, cash measures, and debt measures. Each one comes with a multi-year chart. Near the end is a checklist that scores the company against fixed pass marks.

## Getting plain explanations

Each measure name can be clicked to open the side panel with its definition. Each written question has an "Explain using AI" button. The button draws a sourced answer from the app's financial-text library and the web, using this company's own figures. The question this page answers: is this one company worth more than its current price.
