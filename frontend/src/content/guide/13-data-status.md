# Live data and sample data

The status badge in the top bar tells you where the numbers on screen are coming from. It is a small pill near the right side of the bar, with a colored dot and a short label. Check it before you take any figure seriously.

A green badge reads API online, which means the app is connected to its data server and the numbers are real and current. A red badge reads API offline and mock data, which means the data server is not running. While the app is checking, the badge shows a faint label for a moment.

When the server is off the app does not go blank. It fills the pages with sample numbers instead, so you can still click around, open panels, and learn how every page works. Those numbers are stand-ins only. Do not read them as real figures for any company, and do not write conclusions about a company while the badge is red.

## Checking the connection

Click the badge to open a small box with more detail. It shows the current state and when the app last checked. When the server is off, the box lists the steps to start it. When the server is on, it confirms that live data is flowing. The app rechecks on its own every thirty seconds, so the badge turns green shortly after the server starts.
