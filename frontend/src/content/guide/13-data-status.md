# Live data and sample data

The status badge in the top bar shows where the app's numbers come from. The badge is a small pill near the right side of the bar. A colored dot and a short label tell you the state.

A green badge reads API online. Green means the app is connected to its data server, so the numbers on the page are real and current. A red badge reads API offline and mock data. Red means the data server is not running right now. While checking, the badge shows a faint label for a moment.

When the server is off, the app does not go blank. The app fills the pages with sample numbers instead. Sample numbers let you click around, open panels, and learn how every page works. The sample numbers are stand-ins, so do not read them as real figures for any company.

## Checking the connection

Click the badge to open a small box with more detail. The box shows the current state and when the app last checked. When the server is off, the box lists the simple steps to start it. When the server is on, the box confirms that live data is flowing. The app rechecks the connection on its own every thirty seconds, so the badge turns green soon after the server starts.
